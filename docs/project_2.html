Hamlet Linguistic Analysis

This is a full text analysis project using dialogue from Shakespeare’s play Hamlet. I analyze character strings to answer the following two research questions: 1. Who is the biggest yapper (i.e. who talks the most) in Hamlet? 2. How does language about love compare to language about death?

# Count words in each phrase.
hamlet_words <- hamlet |>
  mutate(
    word_count = str_count(
      dialogue,
      "\\b[[:alpha:]]+\\b"
    )
  )

# Add words per character, per act. 
act_words <- hamlet_words |>
  group_by(act, character) |>
  summarise(
    total_words = sum(word_count),

  )

act_plot <- ggplot(

Question 2: Does love or death conquer all?

Show Code 
love_pattern <- "\\b(love|loves|loved|loving|lover|lovers)\\b"

death_pattern <- "\\b(death|dead|die|dies|died|dying|kill|kills|killed|killing)\\b"

love_death <- hamlet |>
  mutate(
    love_count = str_count(
      str_to_lower(dialogue),
      love_pattern
    ),
    death_count = str_count(
      str_to_lower(dialogue),
      death_pattern
    )
  ) |>
  group_by(act) |>
  summarise(
    Love = sum(love_count, na.rm = TRUE),
    Death = sum(death_count, na.rm = TRUE),
    .groups = "drop"
  ) |>
  pivot_longer(
    cols = c(Love, Death),
    names_to = "Theme",
    values_to = "Occurrences"
  )

Plot 2 (Line Chart)

Show Code 
love_death_plot <- ggplot(
  love_death,
  aes(
    x = act,
    y = Occurrences,
    color = Theme,
    group = Theme,
    text = paste0(
      "Act: ", act,
      "<br>Theme: ", Theme,
      "<br>Occurrences: ", Occurrences
    )
  )
) +
  geom_line(linewidth = 1) +
  geom_point(size = 3) +
  labs(
    title = "Love vs. Death in Hamlet",
    x = "Act",
    y = "Number of Word Occurrences",
    color = "Theme"
  ) +
  theme_minimal()

ggplotly(love_death_plot, tooltip = "text")

Q2 Analysis + Results

This analysis compares the frequency of love and death related words across Hamlet’s 5 acts. It counts related terms using word patterns using an interactive plotly line chart.

Act 1 contains an equal amount of love and death (15 occurrences each). However, the theme of love quickly rises throughout Acts II and III. In Act II, the theme of death is at its lowest, but it peaks around the climax of the play in Act IV. Themes of love peak in Act III, right before Ophelia’s death.

I think its interesting how the theme of love peaks and then drops right before the same happens with the theme of death. I wonder if this could indicate the central focus of the story on violence/death > romance, seeing how taking action/revenge in the face of corruption is central to the climax of the piece, while Hamlet’s romance with Ophelia serves to build up to this turning point.

Conclusion

While I didn’t go into this project with gender in mind, I found that my data inadvertently highlights disparities between the amount of speech male versus female characters have (see Plot 1). Additionally, the fact that there are 10 more occurrences of death than there are of love indicates a greater focus on the theme of death in the play Hamlet.
